# Mensaje de cierre para Gonzalo

Hola Gonzalo, ¿cómo está?

Tal como conversamos durante la entrevista, queríamos compartirle el resultado del desafío que desarrollamos a partir de su experiencia en Smart Contracts.

Implementamos **SmartGuard**, un prototipo web que permite ingresar código Solidity y realizar una revisión inicial basada en un conjunto acotado de patrones de seguridad. Actualmente la herramienta identifica ocho situaciones de revisión, muestra la severidad, el fragmento de código asociado y una recomendación básica. También incorporamos carga de archivos `.sol`, casos de prueba y descarga del reporte en formato JSON.

El proyecto tiene un alcance académico y no busca reemplazar una auditoría profesional. Nos gustaría agradecerle nuevamente por su tiempo y por la orientación entregada durante la entrevista.

Le dejamos el repositorio/resultados para que pueda revisarlos cuando tenga disponibilidad.
